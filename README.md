# Notes on Artificial Intelligence in Neuroimaging Analysis

In the Jupyter notebooks included in this repository, we applied classical machine learning and deep learning to analyze neuroimaging data, using publicly available datasets.
  

## Contents

### 1. Deep Learning for Neuroimaging Analysis: MLP for Age-Related Classification based on Functional Connectivity 

- Notebook: [`functional_connectivity_mlp.ipynb`](functional_connectivity_mlp.ipynb) 
- Notebook description: Modality: Resting-state fMRI; Task: Children vs adults; Models: MLP on tangent space connectivity.


### 2. Deep Learning for Neuroimaging: Convolutional Neural Networks for Age-Related Brain Classification

- Notebook: [`structural_mri_vbm_cnn.ipynb`](structural_mri_vbm_cnn.ipynb)
- Notebook description: Modality: Structural MRI (VBM); Task: Young (< 50 y) vs older (>= 50 y); Models: Linear SVM, 2-D CNN, 3-D CNN, ResNet-18 transfer.
