# Notes on Artificial Intelligence in Neuroimaging Analysis

In the Jupyter notebooks included in this repository, we applied classical machine learning and deep learning to analyze neuroimaging data, using publicly available datasets.
  

## Contents

| Notebook | Modality | Task | Models |
|---|---|---|---|
| [`structural_mri_vbm_cnn.ipynb`](structural_mri_vbm_cnn.ipynb) | Structural MRI (VBM) | Young (< 50 y) vs older (>= 50 y) | Linear SVM, 2-D CNN, 3-D CNN, ResNet-18 transfer |
| [`functional_connectivity_mlp.ipynb`](functional_connectivity_mlp.ipynb) | Resting-state fMRI | Children vs adults | MLP on tangent space connectivity |
